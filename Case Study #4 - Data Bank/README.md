## Case Study #4 - Data Bank

### Description
>This is the FOURD of eight challenges I will be solving over the next eight weeks.

### Problem Statement
> Data Bank is a next-generation digital bank inspired by neo-banks, combining banking, cryptocurrency, and secure data storage. Unlike traditional banks, it offers cloud data storage to customers, with storage limits tied to their account balances.

> As the business scales, the Data Bank team aims to grow its customer base and needs support to analyze usage patterns, forecast storage needs, and calculate growth metrics. 

> This case study focuses on leveraging data to support strategic planning and future expansion.

### What to spect

> 1. Data cleaning.
> 2. Group by aggregates.
> 3. Table joins.
> 4. String transformations.
> 5. Dealing with null values.
> 6. Regular expressions.
> 7. Common table expressions.
> 8. Subjoins.

### Setup and Tools
> 1. Developed using Visual Studio Code (VS Code).
> 2. Written in Transact-SQL (T-SQL).
> 3. Connected to SQL Server through SQL Server Management Studio (SSMS).
> 4. Version control managed with GitHub.

### How to Run
> 1. Open the .sql files in Visual Studio Code or SSMS.
> 2. Execute the scripts against your SQL Server instance.
